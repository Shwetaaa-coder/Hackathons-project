# 😂 Meme Creator

A lightweight and easy-to-use meme creation application that allows users to add custom text, edit images, and generate share-ready memes in seconds.

The project focuses on providing a simple and interactive interface for creating personalized memes without requiring complex editing tools.

## ✨ Features

* 🖼️ Select and work with images
* ✏️ Add custom text to images
* 🎨 Customize meme content
* 👀 Preview the meme before saving
* 💾 Generate and save share-ready memes
* 📱 Simple and responsive user interface
* ⚡ Lightweight and easy to use

## 🛠️ Tech Stack

* **HTML5** – Structure and layout
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and user interactions

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser to run this project locally.

### Installation

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd meme-creator
```

3. Open `index.html` in your web browser.

No additional installation or backend setup is required.

## 🎯 How It Works

1. Select or upload an image.
2. Enter the text you want to display on the meme.
3. Customize the meme as needed.
4. Preview the final result.
5. Generate and save the completed meme.
